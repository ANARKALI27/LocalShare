==================================================
LocalShare - Aasan Manual (Hindi)
==================================================

Ye file bahut simple bhasha mein batati hai ki LocalShare install
kaise karein, use kaise karein, aur Internet par share (Cloudflare)
kaise karein.

ZAROORI BAAT: Pehle ye app ngrok use karta tha, lekin ab sirf
CLOUDFLARE use hota hai - isliye kisi account ya sign up ki zaroorat
nahi hai. Neeche sirf Cloudflare wala tareeka bataya gaya hai.

--------------------------------------------------
1. WINDOWS PAR INSTALL KAISE KAREIN
--------------------------------------------------

1. LocalShareSetup.exe file download karein (ya project se khud
   banayein - neeche "Khud Build Karna" section dekhein).
2. Us file par double-click karein.
3. Agar Windows koi warning dikhaye ("Windows protected your PC"),
   to "More info" par click karein, phir "Run anyway" dabayein. Ye
   warning isliye aati hai kyunki ye app kisi badi company se signed
   nahi hai - nuksaan wali baat nahi hai.
4. Setup ke instructions follow karein - bas Next, Next, Install
   dabate jayein.
5. Install hone ke baad, LocalShare apne aap khul jayega (ya Start
   Menu se kholein).

Uninstall karna ho to: Windows Settings > Apps > LocalShare dhoondhein
> Uninstall dabayein.

--------------------------------------------------
2. LINUX (.deb) PAR INSTALL KAISE KAREIN
--------------------------------------------------

Agar aapke paas localshare_*.deb file hai (Ubuntu, Debian, Linux Mint
jaise systems ke liye):

Tareeka 1 - Double-click se:
  1. .deb file par double-click karein.
  2. Jo Software installer khule, usme "Install" dabayein.
  3. Apna password daalein (agar mange).

Tareeka 2 - Terminal se (zyada bharosemand):
  sudo dpkg -i localshare_*.deb
  sudo apt-get install -f
  (dusri line - agar koi dependency missing ho to ye use theek kar
  degi)

Install hone ke baad, LocalShare apne Applications menu mein mil
jayega.

Uninstall karna ho to:
  sudo apt-get remove localshare

--------------------------------------------------
3. LOCALSHARE USE KAISE KAREIN (BASIC)
--------------------------------------------------

1. LocalShare kholein.
2. Files ya Folder ko khinchkar (drag & drop) window mein daalein -
   ya "Add Files..." / "Add Folder..." button dabayein.
3. Sharing Mode chunein:
   - Local Network Only (default) - sirf un logon ke liye jo aapke
     saath same Wi-Fi par hain. Koi PIN zaroori nahi (chahein to
     laga sakte hain).
   - Global - kisi bhi jagah se kisi ko bhi share karne ke liye,
     chahe wo aapke Wi-Fi par na ho. Isme PIN automatically lag jata
     hai (band nahi kar sakte, security ke liye).
4. "Start Sharing" dabayein. Ek address (link) aur QR code dikh
   jayega.
5. Wo address (ya QR code) jise share karna hai, use bhej dein.
6. Saamne wala vyakti us link ko kisi bhi browser mein khol sakta
   hai - files dekh sakta hai, download kar sakta hai, aur (agar
   folder ke andar hai) apni files upload bhi kar sakta hai.
7. Kaam khatam hone par "Stop Sharing" daba dein.

--------------------------------------------------
4. INTERNET PAR SHARE KARNA (CLOUDFLARE, "GLOBAL" MODE)
--------------------------------------------------

Sabse achhi baat: kuchh bhi install ya setup karne ki zaroorat nahi
hai. Koi account nahi, koi sign up nahi, koi password nahi.

Kaise use karein:

1. LocalShare mein "Global" mode chunein (Local Network Only ki
   jagah).
2. "Start Sharing" dabayein.
3. PEHLI BAAR use karte samay, LocalShare apne aap cloudflared naam
   ki ek chhoti si file (lagbhag 40MB) download kar lega - isme kuchh
   seconds lag sakte hain. Ye sirf EK BAAR hota hai; agli baar se
   turant chalu ho jayega.
4. Kuchh hi seconds mein ek Internet address mil jayega (jaise
   https://kuchh-shabd.trycloudflare.com) - yahi link saamne wale ko
   bhejni hai. Ye link duniya mein kahin se bhi khul sakti hai.
5. PIN bhi screen par dikhega (Global mode mein PIN zaroori hai) - wo
   bhi saamne wale ko bata dein, ya sirf QR code bhej dein (usme PIN
   apne aap shaamil rehta hai).

Agar automatic download fail ho jaye (rare case):

Agar aapke network/firewall ki wajah se automatic download kaam na
kare, to cloudflared ko manually bhi install kar sakte hain:

  Windows (Command Prompt/PowerShell mein):
    winget install --id Cloudflare.cloudflared

  Linux par (aasan tareeka - kisi bhi distro par chalta hai):
    Seedhe binary file download karein (koi package manager setup
    nahi chahiye):
    https://github.com/cloudflare/cloudflared/releases/latest

    (cloudflared-linux-amd64 wali file chunein, phir use executable
    banayein: chmod +x cloudflared-linux-amd64)

  Ya agar Ubuntu/Debian par apt se install karna hai, to pehle
  Cloudflare ki apni repository add karni hogi - poori jaankari yahan
  hai:
    https://pkg.cloudflare.com/index.html
  (sirf "apt-get install cloudflared" se kaam nahi chalega, pehle
  repo add karna zaroori hai)

Install karne ke baad LocalShare ko poori tarah band karke dobara
kholein, phir "Global" mode try karein.

Yaad rakhne wali baatein (Cloudflare ke baare mein):

- Har baar jab aap "Start Sharing" dabate hain, ek NAYA link banta
  hai - purana link "Stop Sharing" dabate hi band ho jata hai.
- Ye link temporary/testing ke liye hai, bahut zyada traffic ya
  hamesha chalu rakhne ke liye nahi bana hai - doston ke saath files
  share karne ke liye bilkul sahi hai.
