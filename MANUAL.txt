==================================================
LocalShare - Simple Manual (English)
==================================================

This file explains, in plain simple language, how to install
LocalShare, how to use it, and how to share over the Internet using
Cloudflare.

IMPORTANT: This app used to use ngrok, but now it uses ONLY
CLOUDFLARE - so no account or sign up is needed at all. Only the
Cloudflare method is explained below.

--------------------------------------------------
1. HOW TO INSTALL ON WINDOWS
--------------------------------------------------

1. Download the LocalShareSetup.exe file (or build it yourself from
   the project - see "Building It Yourself" section below).
2. Double-click that file.
3. If Windows shows a warning ("Windows protected your PC"), click
   "More info", then click "Run anyway". This warning appears because
   the app isn't signed by a big company - it's not harmful.
4. Follow the setup instructions - just keep clicking Next, Next,
   Install.
5. Once installed, LocalShare will open automatically (or open it
   from the Start Menu).

To uninstall: Windows Settings > Apps > find LocalShare > Uninstall.

--------------------------------------------------
2. HOW TO INSTALL ON LINUX (.deb)
--------------------------------------------------

If you have a localshare_*.deb file (for Ubuntu, Debian, Linux Mint,
and similar systems):

Method 1 - Double-click:
  1. Double-click the .deb file.
  2. In the Software installer that opens, click "Install".
  3. Enter your password if asked.

Method 2 - Terminal (more reliable):
  sudo dpkg -i localshare_*.deb
  sudo apt-get install -f
  (the second line fixes any missing dependencies automatically)

After installing, LocalShare will show up in your Applications menu.

To uninstall:
  sudo apt-get remove localshare

--------------------------------------------------
3. HOW TO USE LOCALSHARE (BASICS)
--------------------------------------------------

1. Open LocalShare.
2. Drag and drop files or a folder into the window - or click
   "Add Files..." / "Add Folder...".
3. Choose a Sharing Mode:
   - Local Network Only (default) - for people on the same Wi-Fi as
     you. No PIN needed (you can turn one on if you want).
   - Global - for sharing with anyone, anywhere, even if they're not
     on your Wi-Fi. A PIN is required automatically in this mode (it
     can't be turned off, for security).
4. Click "Start Sharing." An address (link) and a QR code will
   appear.
5. Send that address (or the QR code) to whoever you're sharing
   with.
6. They can open that link in any web browser - view files, download
   them, and (if it's a folder) upload their own files back too.
7. When you're done, click "Stop Sharing."

--------------------------------------------------
4. SHARING OVER THE INTERNET (CLOUDFLARE, "GLOBAL" MODE)
--------------------------------------------------

The best part: there's nothing to install or set up. No account, no
sign up, no password.

How to use it:

1. In LocalShare, select "Global" mode instead of "Local Network
   Only."
2. Click "Start Sharing."
3. The FIRST TIME you use it, LocalShare will automatically download
   a small file called cloudflared (about 40MB) - this can take a
   few seconds. This only happens ONCE; after that it starts
   instantly every time.
4. Within a few seconds you'll get an Internet address (something
   like https://some-words.trycloudflare.com) - send this link to
   whoever you're sharing with. It can be opened from anywhere in the
   world.
5. A PIN will also show on screen (PIN is required in Global mode) -
   share that too, or just send the QR code (which already includes
   the PIN automatically).

If the automatic download fails (rare case):

If your network/firewall blocks the automatic download, you can
install cloudflared manually:

  Windows (in Command Prompt/PowerShell):
    winget install --id Cloudflare.cloudflared

  Linux (easiest way - works on any distro):
    Download the binary file directly (no package manager setup
    needed):
    https://github.com/cloudflare/cloudflared/releases/latest

    (choose the cloudflared-linux-amd64 file, then make it
    executable: chmod +x cloudflared-linux-amd64)

  Or, if you want to install it via apt on Ubuntu/Debian, you first
  need to add Cloudflare's own repository - full instructions here:
    https://pkg.cloudflare.com/index.html
  (just running "apt-get install cloudflared" alone will NOT work -
  you must add their repo first)

After installing, fully close and reopen LocalShare, then try
"Global" mode again.

Things worth knowing about Cloudflare:

- Every time you click "Start Sharing," a NEW link is created - the
  old link stops working as soon as you click "Stop Sharing."
- This link is meant for temporary/testing use, not for huge amounts
  of traffic or staying online permanently - it's perfect for sharing
  files with friends.

--------------------------------------------------
5. BUILDING IT YOURSELF (ONLY IF BUILDING FROM SOURCE CODE)
--------------------------------------------------

Windows:
  build_installer.bat
  (this creates Output\LocalShareSetup.exe)

Linux (.deb):
  ./build_deb.sh
  (this creates a .deb file that can be installed the way described
  above)
