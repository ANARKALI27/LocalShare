==================================================
LocalShare - Simple Manual (English)
==================================================

This file explains, in plain simple language, how to install
LocalShare, how to use it, how to share over the Internet, how to
find and connect to other LocalShare devices, and everything else
that's been added since the last version of this manual.

IMPORTANT: This app uses ONLY CLOUDFLARE for internet sharing - so no account or sign up is needed
for that part at all. Only the Cloudflare method is explained below.

--------------------------------------------------
1. HOW TO INSTALL ON WINDOWS
--------------------------------------------------

1. Download the LocalShareSetup.exe file (or build it yourself from
   the project - see "Building It Yourself" section below).
2. Double-click that file.
3. If Windows shows a warning ("Windows protected your PC"), click
   "More info", then click "Run anyway". This warning appears because
   the app isn't signed by a big company - it's not harmful.
4. Follow the setup instructions - just keep clicking Next, Next,
   Install.
5. Once installed, LocalShare will open automatically (or open it
   from the Start Menu).

To uninstall: Windows Settings > Apps > find LocalShare > Uninstall.

--------------------------------------------------
2. HOW TO INSTALL ON LINUX (.deb)
--------------------------------------------------

If you have a localshare_*.deb file (for Ubuntu, Debian, Linux Mint,
and similar systems):

Method 1 - Double-click:
  1. Double-click the .deb file.
  2. In the Software installer that opens, click "Install".
  3. Enter your password if asked.

Method 2 - Terminal (more reliable):
  sudo dpkg -i localshare_*.deb
  sudo apt-get install -f
  (the second line fixes any missing dependencies automatically)

After installing, LocalShare will show up in your Applications menu.

To uninstall:
  sudo apt-get remove localshare

--------------------------------------------------
3. HOW TO USE LOCALSHARE (BASICS)
--------------------------------------------------

1. Open LocalShare.
2. Drag and drop files or a folder into the window - or click
   "Add Files..." / "Add Folder...".
3. Choose a Sharing Mode:
   - Local Network Only (default) - for people on the same Wi-Fi as
     you. No PIN needed (you can turn one on if you want).
   - Global - for sharing with anyone, anywhere, even if they're not
     on your Wi-Fi. A PIN is required automatically in this mode (it
     can't be turned off, for security).
4. Click "Start Sharing." An address (link) and a QR code will
   appear.
5. Send that address (or the QR code) to whoever you're sharing
   with.
6. They can open that link in any web browser - view files, download
   them, and (if it's a folder) upload their own files back too, or
   drag a file directly onto the page.
7. Want to chat? There's a Messages option too - works from either
   side, supports photos and videos.
8. When you're done, click "Stop Sharing."

--------------------------------------------------
4. SHARING OVER THE INTERNET (CLOUDFLARE, "GLOBAL" MODE)
--------------------------------------------------

The best part: there's nothing to install or set up. No account, no
sign up, no password.

How to use it:

1. In LocalShare, select "Global" mode instead of "Local Network
   Only."
2. Click "Start Sharing."
3. The FIRST TIME you use it, LocalShare will automatically download
   a small file called cloudflared (about 40MB) - this can take a
   few seconds. This only happens ONCE; after that it starts
   instantly every time.
4. Within a few seconds you'll get an Internet address (something
   like https://some-words.trycloudflare.com) - send this link to
   whoever you're sharing with. It can be opened from anywhere in the
   world.
5. A PIN will also show on screen (PIN is required in Global mode) -
   share that too, or just send the QR code (which already includes
   the PIN automatically).

If the automatic download fails (rare case):

If your network/firewall blocks the automatic download, you can
install cloudflared manually:

  Windows (in Command Prompt/PowerShell):
    winget install --id Cloudflare.cloudflared

  Linux (easiest way - works on any distro):
    Download the binary file directly (no package manager setup
    needed):
    https://github.com/cloudflare/cloudflared/releases/latest

    (choose the cloudflared-linux-amd64 file, then make it
    executable: chmod +x cloudflared-linux-amd64)

  Or, if you want to install it via apt on Ubuntu/Debian, you first
  need to add Cloudflare's own repository - full instructions here:
    https://pkg.cloudflare.com/index.html
  (just running "apt-get install cloudflared" alone will NOT work -
  you must add their repo first)

After installing, fully close and reopen LocalShare, then try
"Global" mode again.

Things worth knowing about Cloudflare:

- Every time you click "Start Sharing," a NEW link is created - the
  old link stops working as soon as you click "Stop Sharing."
- This link is meant for temporary/testing use, not for huge amounts
  of traffic or staying online permanently - it's perfect for sharing
  files with friends.

--------------------------------------------------
5. YOUR DEVICE ID (NEW)
--------------------------------------------------

Every LocalShare install now has its own permanent Device ID, like:

    LS-7K4P-92MX

This ID:
  - Is created automatically the first time you open the app
  - Stays exactly the same every time you restart LocalShare
  - Stays the same even if your Wi-Fi/IP address changes, or you
    switch from Wi-Fi to Ethernet
  - Is random and private - it does NOT contain your IP address,
    computer name, or any personal information

Where to find it: Settings > Device. You can also:
  - Change your Device NAME there (the ID itself never changes when
    you do this)
  - Copy your Device ID with one click
  - Regenerate your Device ID if you ever want a fresh one (this
    needs confirmation, since other devices would need to find you
    again afterward)

--------------------------------------------------
6. NEARBY DEVICES (NEW)
--------------------------------------------------

Click the "Nearby Devices" button to see other LocalShare installs
that are currently sharing on your same Wi-Fi/Ethernet network -
found automatically, no setup needed.

  - Each device shows its name, Device ID, and address
  - Click a device (or its "Open" button) to open its address
    directly in your browser - no need to ask them for the link
  - A device only shows up here while it's actively "Start Sharing" -
    if you don't see a device you expect, check that the other
    person has clicked Start Sharing on their end too
  - The list refreshes automatically every few seconds, or click
    Refresh to check right away

Connect by Device ID: instead of browsing the list, you can type a
Device ID directly (like LS-7K4P-92MX) into the box and click
Connect - LocalShare checks your local network first, instantly.

Recent Devices: once you've successfully connected to a device, it's
saved here for quick one-click reconnecting next time - no need to
retype the Device ID again. You can remove any entry you don't want
to keep.

--------------------------------------------------
7. CONNECTING TO A DEVICE ANYWHERE (GLOBAL DEVICE ID CONNECT) (NEW)
--------------------------------------------------

Normally, "Connect by Device ID" only finds devices on your own Wi-Fi.
With one extra (optional, free) setup step, it can also find and
connect to a LocalShare device anywhere else in the world, using
nothing but its Device ID - no address, no port, nothing else to ask
for.

This needs a one-time setup on a free Firebase account (Google's, not
LocalShare's) - full step-by-step instructions are in the separate
GLOBAL_CONNECT_SETUP.md file that comes with this project. Once set
up, paste the resulting database link into Settings > Device >
Connect Globally, and that's it - permanently done, nothing to repeat.

How it actually works, in short: it reuses the same Cloudflare
internet sharing described in section 4 above - there's no separate
server relaying your files. The one-time setup just lets LocalShare
look up "where is this Device ID right now" so you don't have to be
told the address by hand.

If you don't set this up: LocalShare still works exactly the same for
everything else - Connect by Device ID just stays local-network-only,
which is what most people need most of the time anyway.

--------------------------------------------------
8. SUPPORTING THE DEVELOPER (NEW)
--------------------------------------------------

LocalShare is free either way - this is entirely optional. If you'd
like to support its development, go to Settings > About and click
"Thank the Developer" - you'll see a UPI QR code and ID you can pay
to if you want.

That same screen also has an email address for reporting bugs,
sending a message, or suggesting a new feature - always welcome,
whether or not you use the support option.

--------------------------------------------------
9. BUILDING IT YOURSELF (ONLY IF BUILDING FROM SOURCE CODE)
--------------------------------------------------

Windows:
  build_installer.bat
  (this creates Output\LocalShareSetup.exe)

Linux (.deb):
  ./build_deb.sh
  (this creates a .deb file that can be installed the way described
  above)

Important if you're on Windows using WSL (Linux inside Windows): run
these commands from your Linux home folder (like ~/localshare), NOT
from a Windows drive path (like /mnt/c/... or /mnt/b/...). Windows
drives don't support the file permissions the .deb build step needs,
and the build will fail with a permissions error. Copy the project
into your Linux home folder first:

  cp -r /mnt/c/path/to/localshare ~/localshare
  cd ~/localshare
  ./build_deb.sh
